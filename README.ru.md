# QGrab

[English](README.md) · **Русский**

Расширение для браузеров на Chromium (Vivaldi, Chrome, Edge, Brave), которое находит видео и аудио на страницах, включая HLS-потоки, и скачивает их с **оригинальным именем файла**. Расширение является альтернативой Video Downloader Professional, который заменяет оригинальное имя на обезличенное.

## Возможности

- Обнаружение медиафайлов (MP4, WebM, MKV, MOV, MP3, M4A и др.) по `Content-Type` сетевых ответов и по элементам `<video>`/`<audio>`.
- Обнаружение HLS-потоков (`.m3u8`) с выбором качества и оценкой размера файла.
- Скачивание HLS-потоков, в том числе зашифрованных AES-128: параллельная загрузка сегментов, повторные попытки, возможность сохранить файл без сегментов, которые не удалось загрузить.
- Отдельная звуковая дорожка HLS-потока сохраняется вторым файлом.
- Автоматическая передача `Referer` исходной страницы, благодаря чему CDN, проверяющие этот заголовок, не отклоняют загрузку.
- Скрытие лишних запросов: сегментов потоков, фрагментов MSE, мелких файлов (превью, звуков интерфейса), фрагментов YouTube.
- Возможность изменить имя файла в окне расширения перед загрузкой.
- Интерфейс на русском и английском языках; светлая и тёмная темы.

## Определение имени файла

Имя берётся из первого доступного источника:

1. Заголовок ответа `Content-Disposition`, включая `filename*=UTF-8''…` (RFC 5987) и UTF-8-имена, пришедшие в искажённом виде как Latin-1.
2. Имя, встроенное в ссылку: `response-content-disposition` подписанных ссылок S3/CloudFront, параметры `filename`, `file`, `name`.
3. Последний сегмент пути URL с раскодированием процентной кодировки (`My%20Trip.mp4` → `My Trip.mp4`).
4. Для потоков с бессмысленным именем манифеста (`index.m3u8`, `master.m3u8`) — ближайшая осмысленная родительская папка (`/movies/Big_Buck_Bunny/hls/index.m3u8` → `Big_Buck_Bunny`).
5. Заголовок страницы.

Бессмысленным считается имя, которое является типичным именем манифеста или CDN (`index`, `playlist`, `chunklist_b800000`, `video`), обозначением качества (`1080p`), числом, хэшем или UUID.

Режим именования выбирается в настройках:

| Режим | Результат |
|---|---|
| Умный (по умолчанию) | Оригинальное имя; заголовок страницы, если оригинальное имя бессмысленное |
| Всегда оригинальное | Имя с сервера или из ссылки без исключений |
| Заголовок страницы | Заголовок страницы, на которой найдено медиа |
| Заголовок страницы + оригинальное имя | Например, `Лекция 5 - lecture5_part2.mp4` |

Недопустимые в именах файлов символы заменяются (`:` и `|` — на ` - `, `/` — на `-`), к зарезервированным в Windows именам (`CON`, `NUL` и т. п.) добавляется префикс, длина ограничивается 150 символами.

## Установка

Расширение устанавливается как распакованное:

1. Открывается страница `vivaldi://extensions` (или `chrome://extensions`, `edge://extensions`).
2. Включается **режим разработчика**.
3. Выбирается **«Загрузить распакованное расширение»**, затем папка проекта (та, в которой находится `manifest.json`).

Если одновременно установлен Video Downloader Professional, его рекомендуется отключить: его обработчик `onDeterminingFilename` может перезаписывать имена, назначенные другими расширениями.

## Использование

Медиа обнаруживается в момент загрузки страницей, поэтому сначала требуется запустить воспроизведение. На значке расширения отображается количество найденного на текущей вкладке. В окне расширения перечислены найденные элементы с размером или длительностью, выбором качества для HLS, полем имени, кнопкой копирования ссылки и кнопкой загрузки.

Обычные файлы передаются в менеджер загрузок браузера напрямую. HLS-поток скачивается в отдельной фоновой вкладке, где отображаются прогресс, скорость и оставшееся время; после сохранения файла вкладка закрывается (настраивается).

## Настройки

- Режим именования файлов (см. выше).
- Подпапка внутри папки загрузок.
- Запрос места сохранения для каждого файла.
- Количество параллельных загрузок сегментов HLS (1–16).
- Закрытие вкладки потока по завершении загрузки.
- Минимальный размер отображаемых файлов (по умолчанию 500 КБ).

## Ограничения

- HLS-потоки сохраняются в исходном контейнере: MPEG-TS (`.ts`) для классических потоков и MP4 для потоков во фрагментированном MP4. Файл `.ts` воспроизводится VLC, mpv и большинством плееров; преобразование в MP4 без потери качества выполняется командой `ffmpeg -i video.ts -c copy video.mp4`.
- Если видео и звук потока являются отдельными дорожками, они сохраняются двумя файлами; объединение выполняется командой `ffmpeg -i video.mp4 -i "video (аудио).m4a" -c copy out.mp4`.
- DASH-потоки (`.mpd`) отображаются в списке, но не скачиваются; их ссылку можно скопировать для yt-dlp или ffmpeg.
- Потоки, защищённые DRM (SAMPLE-AES, Widevine, FairPlay, PlayReady), не поддерживаются.
- Для прямых эфиров сохраняются только сегменты, доступные в момент загрузки.
- HLS-поток собирается в памяти браузера перед сохранением; для очень длинных видео с высоким битрейтом требуется соответствующий объём оперативной памяти.
- YouTube не поддерживается: его плеер загружает видео и звук фрагментами, которые невозможно сохранить как файлы.

## Разрешения

| Разрешение | Назначение |
|---|---|
| `webRequest`, доступ ко всем сайтам | Чтение заголовков ответов (тип, размер, имя файла) медиазапросов |
| `downloads` | Сохранение файлов под выбранным именем |
| `declarativeNetRequestWithHostAccess` | Передача `Referer` страницы в собственных запросах расширения |
| `storage` | Настройки и список найденного, который сохраняется при перезапуске service worker |

Расширение не передаёт данные на сторонние серверы.

## Структура проекта

```
manifest.json
src/background.js        service worker: обнаружение, список элементов, запуск загрузок
src/content.js           источники <video>/<audio> на странице
src/lib/                 общие модули: имена, типы медиа, парсер HLS, правила Referer, настройки
src/popup/               список найденного
src/downloader/          страница загрузки HLS-потока
src/options/             страница настроек
_locales/en, _locales/ru строки интерфейса
tools/make-icons.mjs     генератор иконок (без зависимостей)
tools/e2e.mjs            сквозной тест в настоящем браузере
tests/                   модульные тесты
```

## Разработка

Для тестов и вспомогательных скриптов требуется Node.js 18 или новее; само расширение не требует сборки.

- `npm test` запускает модульные тесты (имена, типы медиа, парсер HLS).
- `node tools/e2e.mjs <путь к исполняемому файлу браузера>` запускает браузер с временным профилем, поднимает тестовую страницу, скачивает всё найденное и проверяет имена файлов, расшифровку HLS и заголовок `Referer`. При `SHOTS=1` дополнительно сохраняются снимки окна расширения.
- `npm run icons` заново создаёт иконки.

Для Vivaldi в Windows сквозной тест запускается так:

```
node tools/e2e.mjs "%LOCALAPPDATA%\Vivaldi\Application\vivaldi.exe"
```
